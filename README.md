# Husen Admin

Panel administrasi terpisah untuk mengelola konten House of Art.

```powershell
npm install
npm run dev
npm run lint
npm run build
```

Isi `.env.example` pada `.env.local` untuk menyiapkan integrasi Supabase mendatang. Data login dan konten contoh hanya tersedia dalam mode development.

Sumber kebenaran skema basis data berada di `supabase/migrations/`.
